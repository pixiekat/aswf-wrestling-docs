# About this Document

This is a repository for the documentation, bios, cards, and history of *All Star Wrestling Federation*, my personal e-fed for close to twenty years. Currently I'm working on rebirthing it as a game on [Pro Wrestling Sim](https://store.steampowered.com/app/1157700/Pro_Wrestling_Sim/).

# All Star Wrestling Federation: Tradition Rules

*All Star Wrestling Federation* is a hybrid wrestling organisation that aims to strike a balance between “old-school” and “new-school”.

## Quick Statistics

- Founded: 1991
- Headquarters: Toronto, Ontario
- Website: [Official](https://www.aswfwrestling.com)

## Programs

- **[Turbulance](http://aswf.integraldata.cc/shows/turbulance)**: Flagship program, airs Tuesday at 21:00. Hosted by Dan Crawford, Rex Roseman, and J. Clear
 
- **[Thrasher!](http://aswf.integraldata.cc/shows/thrasher)**: Secondary program, airs Friday at 22:00. Hosted by J. Clear and Rikky Bull. Aims to be a throwback to the wrestling shows of the 70's and 80's.

- **[In Your Face!](http://aswf.integraldata.cc/shows/inyourface)**: Wrap up and review, airs online several times. Hosted by Rex Roseman
 
- **[ASWF\.com Radio](http://aswf.integraldata.cc/radio)**: Updates throughout the day (and wrap up on Sunday). On demand through [ASWF.com](http://aswf.integraldata.cc). Hosted by Ken Steeves.
